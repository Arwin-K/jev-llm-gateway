# Benchmark adapters and protocol

GSM8K uses `openai/gsm8k`, `main`, source `train` and the final `####` answer segment. The zero-shot prompt includes only the question, with an explicit final-answer format. Its source rows have no intrinsic ID, so `source_split:index` is used with the pinned dataset revision. MMLU uses `cais/mmlu`, `all`, source `test`; it preserves the four source options in order and maps the zero-based answer index to A–D. Subject and row index are retained. The target manifest's `test` label is separate from MMLU's official source `test` split.

MBPP uses Google Research's `sanitized-mbpp.json`, pinned to a repository commit. The prompt includes only the task description; `test_list` and `test_imports` are retained privately for scoring. The benchmark's published protocol includes visible tests, but this project's zero-shot, hidden-tests protocol deliberately differs. The sanitized collection is smaller than the full MBPP set; it cannot supply 600 independent code prompts. Google Research's official ID ranges and terms should be reviewed before redistribution. Dataset snapshots are downloaded explicitly, kept private, and never shipped in source control. Source links: https://huggingface.co/datasets/openai/gsm8k ; https://huggingface.co/datasets/cais/mmlu ; https://github.com/google-research/google-research/blob/master/mbpp/README.md .

Code scoring uses Docker only, with a pinned Python image tag, no network, dropped capabilities, no new privileges, a nonroot UID, read-only root and bind mount, bounded memory/CPU/processes, and a timeout. A timed-out container is force removed. Docker Engine and image availability must be checked on the actual Mac. Containers reduce risk; they are not an absolute security boundary. Missing Docker means scoring is blocked, never host-executed.

The frozen target is 2,500 source prompts: 1,100 GSM8K, 1,000 MMLU, 400 sanitized MBPP. Selection uses SHA-256 of a fixed seed and source group, then assigns 60/20/20 within each task (1,500/500/500 total). Exact case/whitespace-normalized prompt variants share a group; one representative is retained. This does not detect semantic paraphrases. GSM8K official train and MMLU official test rows are repartitioned into project train/validation/test; these project labels are not official benchmark split claims. The held-out project test is gated by an explicit flag and must remain unused until final configuration freeze. Raw source snapshots and prompt text are private run inputs; the committed manifest should contain IDs, hashes, split, revision and counts only unless redistribution terms are cleared.

Snapshot preparation now uses revision-specific Hugging Face Parquet files (read by optional DuckDB) and a revision-specific Google Research MBPP JSON file. This bypassed a real HTTP 429 from the dataset viewer API. The observed pinned source counts were 7,473, 14,042, and 427 respectively. The committed manifest index has metadata only; `runs/day2-manifest.jsonl` contains private prompt and answer data.
