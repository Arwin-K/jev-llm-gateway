# Benchmark adapters and protocol

GSM8K uses `openai/gsm8k`, `main`, source `train` and the final `####` answer segment. The zero-shot prompt includes only the question, with an explicit final-answer format. Its source rows have no intrinsic ID, so `source_split:index` is used with the pinned dataset revision. MMLU uses `cais/mmlu`, `all`, source `test`; it preserves the four source options in order and maps the zero-based answer index to A–D. Subject and row index are retained. The target manifest's `test` label is separate from MMLU's official source `test` split.

MBPP uses Google Research's `sanitized-mbpp.json`, pinned to a repository commit. The prompt includes only the task description; `test_list` and `test_imports` are retained privately for scoring. The benchmark's published protocol includes visible tests, but this project's zero-shot, hidden-tests protocol deliberately differs. The sanitized collection is smaller than the full MBPP set; it cannot supply 600 independent code prompts. Google Research's official ID ranges and terms should be reviewed before redistribution. Dataset snapshots are downloaded explicitly, kept private, and never shipped in source control. Source links: https://huggingface.co/datasets/openai/gsm8k ; https://huggingface.co/datasets/cais/mmlu ; https://github.com/google-research/google-research/blob/master/mbpp/README.md .
