# Full Jev project

This starter supersedes the earlier reduced-scope plans. It contains instructions, 108 commit checkpoints, extensive Codex prompts, and finished handwritten study notes. The application has not been implemented here.

1. Read SETUP_AND_BUILD_GUIDE.md.
2. Open this folder or merge these instructions into your existing project without deleting work.
3. Install the Mac/Colab prerequisites and configure your accounts/budget.
4. Paste prompts/00_bootstrap.md into Codex.
5. Paste prompts/01_day1.md through prompts/06_day6.md in order.
6. Work through six groups of three meaningful commit checkpoints per day.
7. Copy HANDWRITTEN_JOURNAL.md passages into your physical journal.
8. At close paste prompts/end_day_journal.md for actual-work prose.

No journal application, journal CLI, mastery tracker, or personal reflection forms are included.

The commit plan is requested work, not a completed Git history. Full verification depends on actual hardware/provider access and bounded evaluation runs.
