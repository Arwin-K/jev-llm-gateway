# Contributor and artifact provenance

## Rights and distribution

This repository has **no declared project license**. `CONTRIBUTING.md` already records that decision; this checkpoint does not add one or grant redistribution rights. Source dependencies, model weights, and datasets carry their own terms. Before sharing a fork, model artifact, benchmark snapshot, or result containing prompt/answer text, inspect the current upstream terms and any account-specific conditions. The committed `docs/day2-manifest-index.jsonl` contains only IDs, hashes, revisions, and split metadata; raw prompts, references, MBPP tests, provider responses, and credentials remain in ignored private directories.

The benchmark sources are [GSM8K](https://huggingface.co/datasets/openai/gsm8k) at `740312add88f781978c0658806c59bc2815b9866`, [MMLU](https://huggingface.co/datasets/cais/mmlu) at `c30699e8356da336a370243923dbaf21066bb9fe`, and [Google Research sanitized MBPP](https://github.com/google-research/google-research/tree/master/mbpp) at `1ae1fded5c616deb6b4652818588577e8fca0f06`. `src/jev_gateway/evaluation/datasets.py` defines the pinned retrieval and projection. These source links identify provenance, not permission to redistribute their contents.

## Model and derived-artifact identity

The Mac examples target native Ollama `qwen2.5:1.5b` and `qwen2.5:7b`; Colab proposes [Qwen2.5 1.5B Instruct](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct) at a resolved commit. The embedding adapter proposes [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2). The local [Strands Decider](https://github.com/strands-labs/strands-decider) adapter needs a separately obtained compatible checkpoint. The frontier and Jev models are API-configured. Example tags and notebook versions are candidates until actual downloaded digests/revisions are recorded. No trained DistilBERT artifact, local embedding index, or Strands checkpoint is distributed by this repo.

To regenerate routing labels, use `jev eval-prepare`, the bounded Day 2 runner across the **same three generation identities/settings**, and the [Day 3 training procedure](DAY3_HANDOFF.md). Save model/tokenizer commit, training IDs, validation IDs, preprocessing, label mapping, generation settings fingerprint, and backend identities in artifact metadata. `routing.artifact.inspect` refuses a missing, untrained, or incompatible artifact. Changing a generator model, tokenizer, prompt template, output cap, scoring rule, or serving behavior that changes answers invalidates previous success labels. Update Jev backend descriptions and prompted-router examples, collect new train/validation observations, retrain or reselect the fallback and thresholds, then create a new freeze. Never silently mix old labels with a new backend.

The Day 6 performance notebook uses a Git archive SHA-256 and full source revision. Its environment JSON records actual GPU, driver, Python, package versions, model revision, dtype, and config hash. Raw benchmark and profile files carry unique run IDs and input hashes. A notebook runtime is ephemeral; download artifacts before disconnecting and keep raw outputs immutable. A profiler trace is diagnostic evidence and cannot replace unprofiled timing runs.

## Fork and contribution workflow

Forks should substitute local model tags and provider credentials through environment configuration, never by committing secrets. Paid paths stay disabled until explicit positive request/token/USD caps, credentials, model identity, and dated sourced rates are configured. Keep the normal package CUDA-free; install training, embeddings, or vLLM only in the appropriate optional environment. Run focused offline checks for changed modules and the full suite for shared contracts. For a claimed experiment, retain the raw record, exact command, source/config hashes, host/device facts, failures, and a report generated from the raw inputs. Update `STATUS.md`, `ENVIRONMENT.md`, `DECISIONS.md`, and `EXPERIMENTS.md` as engineering evidence. A public release or upload requires a separate license/rights review and destination instruction.
